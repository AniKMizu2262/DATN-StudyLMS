# DATN-LMS_Study

**Hệ thống quản lý học tập tích hợp trợ lý ảo hỏi đáp theo tài liệu môn học**  
*Learning Management System with a Course Document-Based AI Question Answering Assistant*

## 1. Giới thiệu | Overview

**Tiếng Việt**

DATN-LMS_Study là đồ án tốt nghiệp xây dựng hệ thống quản lý học tập (LMS) tích hợp trợ lý ảo AI. Hệ thống hướng đến việc hỗ trợ giảng viên quản lý tài liệu môn học và giúp sinh viên tra cứu kiến thức thông qua hình thức hỏi đáp dựa trên nội dung tài liệu được cung cấp.

**English**

DATN-LMS_Study is a graduation project that develops a Learning Management System (LMS) integrated with an AI assistant. The system aims to help lecturers manage course materials and enable students to retrieve knowledge through question answering grounded in provided learning documents.

## 2. Mục tiêu | Objectives

- Quản lý người dùng và vai trò trong hệ thống.  
  Manage users and roles within the system.
- Quản lý môn học và tài liệu học tập.  
  Manage courses and learning materials.
- Hỗ trợ sinh viên hỏi đáp dựa trên tài liệu môn học.  
  Support document-based question answering for students.
- Cung cấp nguồn trích dẫn để người dùng kiểm chứng câu trả lời.  
  Provide source citations so users can verify AI-generated answers.
- Xây dựng hệ thống dễ bảo trì, dễ mở rộng và có thể triển khai trực tuyến.  
  Build a maintainable, extensible system that can be deployed online.

## 4. Phạm vi chức năng | Planned Scope

- Quản lý tài khoản và phân quyền người dùng.  
  User account and role management.
- Quản lý môn học và tài liệu học tập.  
  Course and learning material management.
- Tải lên, xử lý và lập chỉ mục tài liệu.  
  Document upload, processing, and indexing.
- Hỏi đáp theo nội dung tài liệu, kèm nguồn tham khảo.  
  Document-grounded question answering with source references.
- Lưu trữ và xem lại lịch sử hội thoại.  
  Conversation history storage and retrieval.
